# Userbotpromotele
Userbottele is a user bot designed specifically for promotion purposes, automatically sending messages to all groups you are a member of using the command /promote [text] &amp; Also command /help for all command
# Script Userbot [PROMOTER]
```bash
pkg update
pkg upgrade
pkg install python
pkg install git
pkg install python-pip
pip install telethon
```
Once the packages are installed, follow the steps below:

1. Clone the repository:

git clone https://github.com/Ainuncantik/Userbotpromotele.git

2. Navigate to the cloned directory:

cd Userbotpromotele

3. Install required dependencies:

pip install -r requirements.txt

4. Run the script:

python UserBot.py

Commands

Promote

Gunakan perintah berikut untuk mengirim pesan promosi:

/promote [teks]

Contoh:

/promote Halo, ini pesan promosi saya.

Help

Untuk melihat daftar perintah:

/help

Requirements

* Python
* Git
* Python-pip
* Telethon
5. Enter your phone number (+62) and Telegram SMS code when prompted.
